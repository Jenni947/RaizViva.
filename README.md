
# 🌱 RaizViva — Catálogo Digital da Natureza

**Conhecer para preservar. Tecnologia para cultivar o futuro.**

O RaizViva é um projeto independente que aproxima a tecnologia da biodiversidade brasileira, reunindo informações sobre árvores nativas, nomes populares, nomes científicos, fotografias e características botânicas.

## 🌳 Funcionalidades

- 📷 Fotografias ilustrativas de espécies nativas.
- 🌿 Nomes populares e científicos.
- 🔎 Pesquisa por nome popular ou científico.
- 🗂️ Filtros para encontrar espécies.
- 📚 Informações e características botânicas.
- 📱 Interface adaptada para celulares e computadores.
- 🌎 Valorização da biodiversidade brasileira.

## 🍃 Espécies apresentadas

| Nome popular | Nome científico |
|---|---|
| Ipê-amarelo | *Handroanthus albus* |
| Ingá | *Inga vera* |
| Angico-vermelho | *Anadenanthera colubrina* |
| Sangra-d'água | *Croton urucurana* |
| Pau-brasil | *Paubrasilia echinata* |

## 💻 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## 🚀 Como executar

1. Acesse o repositório no GitHub.
2. Baixe os arquivos do projeto.
3. Abra `index.html` em um navegador.
4. Explore o catálogo e utilize a pesquisa.

## 🎯 Objetivo

Desenvolver uma experiência digital para incentivar a educação ambiental, valorizar as espécies nativas e divulgar conhecimentos botânicos.

## 🔭 Futuras funcionalidades

- Passaporte digital individual para cada muda.
- QR Code para identificação de árvores.
- Registro de crescimento e desenvolvimento.
- Mapa de áreas de plantio.
- Catálogo ampliado de espécies brasileiras.
- Informações sobre sementes, frutos e floração.

## 📷 Créditos das imagens

As fotografias são utilizadas como referências visuais, com links para páginas do Wikimedia Commons. Consulte a licença e as atribuições exigidas para cada imagem antes de reutilizá-la.

## ⚠️ Aviso de independência

O RaizViva é um projeto independente, educacional e demonstrativo. Não possui vínculo, parceria, patrocínio ou aprovação de instituições públicas ou privadas.

As informações botânicas devem ser conferidas em fontes científicas e bases especializadas. Os nomes populares podem variar conforme a região.
